# Zepia Playground

> A modern multi-utility toolbox web application built with **Vue 3**, **Vite**, and **Vuetify 3**. Hosted directly on [GitHub Pages](https://zepiawork.github.io/).

---

## 🛠️ Built With

- ⚡ **[Vue 3](https://vuejs.org/)** & **[Vite](https://vitejs.dev/)** - Fast Composition API SPA
- 🎨 **[Vuetify 3](https://vuetifyjs.com/)** - Material Design UI component library
- 🌐 **[Vue I18n 11](https://vue-i18n.intlify.dev/)** - Multi-language support (EN, TH, JA, DE)
- 🔤 **[Kuroshiro](https://github.com/dodo/kuroshiro)** & **[Kuromoji](https://github.com/takuyaa/kuromoji.js)** - Japanese morphological analysis & transliteration
- 📷 **[QRCode](https://www.npmjs.com/package/qrcode)** - High-fidelity QR code rendering with logo overlay

---

## 🧰 Available Tools

1. **Percentage Calculator**: Basic percentages, increases, decreases, percentage of values, percentage change, and visual bar representations.
2. **Byte Unit Converter**: Live conversions between Binary (IEC: KiB, MiB, GiB, TiB, PiB), Decimal (SI: kB, MB, GB, TB, PB), and Network Bit rates.
3. **Car Detail Generator**: Realistic ISO 3779 VIN generation with valid modulo-11 check digit verification, engine numbers, and batch CSV export.
4. **Thai Citizen ID Generator & Validator**: Checksum-compliant Thai ID generator, live validator, ID anatomy guide, and bulk export.
5. **Expense Proportional Overview**: Visual budget overview scaled by proportion of expenditure with LocalStorage persistence and JSON/CSV export.
6. **Kanji to Romaji Translator**: Convert Japanese Kanji/Kana text into Romaji, Hiragana, Katakana, and Furigana (HTML Ruby / brackets).
7. **QR Code Generator**: Create styled QR codes with presets (Wi-Fi, vCard, Email, SMS, URL), colors, quiet zone margins, and central logo overlay.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Type Checking & Linting
```bash
npm run typecheck
npm run lint
```

### Build for Production
```bash
npm run build
```
